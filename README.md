# 🎮 Games

A collection of browser-based games and game development experiments built as part of my personal game development projects.
This repository serves as a growing portfolio of playable web game prototypes and mechanics-focused implementations.

## 📂 Projects

| Game | Description | Main Technologies | Folder | Demo |
|---|---|---|---|---|
| **BLOKK (Tetris)** | A classic Tetris-style browser game featuring scoring, levels, line clears, hold piece, next preview, keyboard and touch controls, and local high-score tracking. | HTML, CSS, JavaScript, Canvas API, Local Storage API | [`tetris/`](./tetris) | No verified hosted demo |

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Theofil87/Games.git
cd Games
```

Then open any project folder and run it locally. To play BLOKK (Tetris), open `tetris/index.html` in a modern web browser.

Alternatively, serve the repository with a local HTTP server:

```bash
cd tetris
python -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.
